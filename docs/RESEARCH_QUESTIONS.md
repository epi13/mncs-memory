# Research questions

The first slice is designed to measure, rather than assume, these questions:

1. Does specialist administration reduce irrelevant delivery context?
2. How much compression is possible before required-fact correctness falls?
3. Which operations remain reliably deterministic?
4. Which ambiguity classes benefit from tiny learned models?
5. How often is escalation necessary, and what bounded context does it expose?
6. Does structured consolidation beat raw similarity under temporal change and
   contradiction?
7. Can lineage-backed replay repair a faulty processor without losing evidence?
8. Which provider boundaries produce clean training tasks?
9. What is the cost of multiple tiny specialists versus one larger memory model?
10. Which memory semantics should be exported to other MNCS projects?
11. What additional MNCS abstractions are demanded by real memory workloads?

Negative results are first-class. A future corpus may show simple retrieval
winning on recall, deterministic logic outperforming a learned provider, or a
large model being necessary for a particular ambiguity class.
