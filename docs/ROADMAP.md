# Roadmap

## Done in this slice

- linked MNCS semantic policy modules;
- deterministic typed specialist contracts;
- append-oriented observations and provenance-bearing claims;
- six-way disposition, current belief, contradictions, supersession, and
  explicit `UNKNOWN`;
- budgeted semantic capsules with opt-in provenance/raw history;
- explicit escalation audit records;
- faulty-provider replay from retained observations;
- bounded corpus and raw/retrieval/MNCS comparison artifact;
- body/SSA plus research-bytecode/portable-WASM attempts.

## Next experiments

1. Add a replay dependency index so only affected descendants are recomputed.
2. Add a frozen tiny relevance or entity model behind the same typed contract.
3. Compare a vector-style baseline without changing the semantic API.
4. Add task-specific answer oracles beyond string/value membership.
5. Measure processor work and resource budgets across larger bounded corpora.
6. Test a persistent snapshot/transaction adapter without making SQLite part of
   the semantic model.
7. Revisit language pressure only when these workloads require an abstraction
   that cannot be expressed naturally in current MNCS.
